Medical Equipment · Condition Screening

คัดกรองเครื่องมือแพทย์เพื่อประเมินการเสื่อมสภาพ

นำเข้าทะเบียนครุภัณฑ์จาก Excel ระบบจะคัดเฉพาะรายการที่เข้าเกณฑ์ ประเมินราคาให้เครื่องที่ราคาเป็น 0 บาท (เช่น ได้จากเงินบริจาค) แล้วส่งออกเป็นไฟล์แยกหน่วยงานให้ลงความเห็น

● ไฟล์ประมวลผลในเบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งออกไปที่ใด

1

นำเข้าไฟล์ทะเบียนครุภัณฑ์

ข้อมูลตัวอย่าง

2

จับคู่คอลัมน์

ระบบเดาจากชื่อหัวคอลัมน์ ตรวจทานและแก้ได้
3

เกณฑ์การคัดกรอง

A
ราคา ≥ บาท และอายุมากกว่า ปี
B
ราคา ≥ บาท และอายุตั้งแต่ ปีขึ้นไป
C
เครื่องมือจำเป็นตามรายการด้านขวา อายุมากกว่า ปี (ทุกราคา)
A*
ราคา 0 บาท ใช้ราคากลางของเครื่องชนิดเดียวกันที่มีราคาในไฟล์แทน แล้วเทียบกับเกณฑ์ A

ราคาประเมินใช้ค่ามัธยฐานของเครื่องยี่ห้อและรุ่นเดียวกันก่อน ถ้าไม่มีจึงใช้เครื่องชนิดเดียวกันทั้งหมด ค่ามัธยฐานไม่ถูกดึงสูงหรือต่ำเกินจริงจากเครื่องราคาผิดปกติ ปรับราคาเองได้ในตารางราคาอ้างอิงด้านล่าง

4

ผลการคัดกรอง

หน่วยงานเลขครุภัณฑ์ชื่อครุภัณฑ์ยี่ห้อ / รุ่นได้มาอายุ (ปี)ราคาในทะเบียนราคาที่ใช้ประเมินเข้าเกณฑ์

สรุปตามหน่วยงาน

หน่วยงานครุภัณฑ์ทั้งหมดเข้าเกณฑ์AA*BCต้องตรวจสอบ

ราคาอ้างอิงสำหรับเครื่องราคา 0 บาท

ชนิดที่มีเครื่องราคา 0 บาท พร้อมราคากลางจากเครื่องชนิดเดียวกันในไฟล์ กรอกช่อง “กำหนดเอง” เพื่อใช้ราคาที่ทราบ เช่น ราคากลางของกรมบัญชีกลาง

ชนิดเครื่องมือเครื่องราคา 0เครื่องที่มีราคาต่ำสุดมัธยฐานสูงสุดกำหนดเอง (บาท)
