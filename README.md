# คัดกรองเครื่องมือแพทย์เสื่อมสภาพ

เว็บแอปหน้าเดียวสำหรับนำเข้าทะเบียนครุภัณฑ์จาก Excel/CSV คัดเครื่องมือแพทย์ที่ควรประเมินการเสื่อมสภาพ และส่งออกไฟล์ Excel แยกตามหน่วยงานให้หน่วยงานลงความเห็น

## เกณฑ์ (ปรับได้ในหน้าเว็บ)
- **A** ราคา ≥ 100,000 บาท และอายุ > 5 ปี
- **A\*** ราคา 0 บาท (เช่น ได้จากเงินบริจาค) ใช้ราคามัธยฐานของเครื่องยี่ห้อ/รุ่นเดียวกัน หรือชนิดเดียวกันในไฟล์แทน แล้วเทียบเกณฑ์ A
- **B** ราคา ≥ 100,000 บาท และอายุ ≥ 10 ปี

ไม่นำรายการที่สถานะจำหน่าย/รอจำหน่าย และรายการในบัญชียกเว้น (ตู้ข้างเตียง ตู้เก็บ รถเข็น เก้าอี้ทั่วไป ฯลฯ) มาคัดกรอง

## การใช้งาน
เปิด `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages ไฟล์ข้อมูลประมวลผลในเบราว์เซอร์เท่านั้น ไม่ถูกส่งไปที่ใด
